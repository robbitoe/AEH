# 10. Glosario

| Término | Significado |
|---|---|
| Product Constitution | Versión aprobada de los objetivos, límites y reglas de aprobación del producto. |
| Outcome | Resultado observable con criterios de aceptación. |
| Phase | Unidad de trabajo ordenada o condicionada dentro de un outcome. |
| Execution Contract | Límites y condiciones bajo los que se ejecuta una fase. |
| Execution | Instancia de ejecución de un outcome con versiones de contratos fijadas. |
| ExecutionAttempt | Invocación individual de una fase, incluido un reintento o fallback. |
| Provider Adapter | Frontera sustituible que traduce el contrato a una invocación y normaliza su resultado. |
| ProviderCapabilitySnapshot | Registro fechado de las señales observadas sobre capacidad. |
| Evidence | Artefacto verificable vinculado al criterio y al intento que lo originó. |
| Verification | Dictamen emitido al comprobar evidencia contra criterios de aceptación. |
| Checkpoint | Referencia a un punto de recuperación evaluado para evitar duplicar efectos. |
