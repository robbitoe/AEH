AEH 1.0.0 is the first release of the Autonomous Engineering Harness: a single Go binary that takes a product from an idea to verified, documented code by orchestrating agent CLIs (Codex CLI, Claude Code, a local model) under deterministic gates, independent reviews and a private product memory.

New to AEH? Read the [getting started guide](https://github.com/robbitoe/aeh/blob/v1.0.0/docs/getting-started.md).

## What it does

- **Discover.** `aeh discover` turns a vague idea into a book of specs through rounds of questions: vision, data model, one spec per feature with acceptance criteria, and HTML mockups. You choose the technology stack. `aeh adopt` documents an existing system area by area, up to characterization tests that pass on the current code.
- **Approve.** You approve each feature at an exact version. Approved versions never change; later versions are planned as a delta of new, changed and removed criteria, with clarifications, queued approvals and declared path moves.
- **Build.** `aeh plan` has an independent test author write acceptance tests. The runner checks that they fail before the feature exists, has them reviewed, and seals them. `aeh run` drives implementers through a fresh worktree per attempt. Each candidate passes deterministic gates in a fixed order (sealed-test hashes, scope, drift, build, test, acceptance) and independent QA, security and DBA reviews from another provider. When an attempt fails, the run retries with the failure as feedback, escalates to the next profile, or pauses with a question. Accepted work lands on `aeh/<ID>`; you merge it.
- **Remember.** A local, private memory (`.aeh/memory/`, its own Git repository, never published) keeps versioned specs, implementations and the history of every decision.
- **Sandbox (optional).** Build, test and acceptance commands can run in a local Docker container with no network, no credentials and no Git metadata, with an integrity check after every command. See `docs/sandbox.md`. Agents still run on the host in this release.

## Install

Download the archive for your system below, check it against `checksums.txt`, and put `aeh` on your `PATH`. Or, with Go 1.24+:

```sh
go install github.com/robbitoe/aeh/cmd/aeh@v1.0.0
```

## Known limitations

- Tested on Windows and Linux; macOS builds but has not been tested.
- Agent CLIs run with your user's permissions, limited only by their own sandbox flags. Use trusted repositories and profiles.
- `aeh do` cannot resume after a block.
- On Windows, gate commands without the sandbox run through `cmd /C`; with the sandbox they run through `sh -c` in Linux containers.
- A CLI that reports its usage limit only in its message (Claude Code exits 1 with "You've hit your ... limit") is not recognized as a quota signal: its attempts count as failures. Rerun after the limit resets (`aeh answer`, then `aeh run`).
